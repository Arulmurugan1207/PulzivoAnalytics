What they are for

The UTM builder writes the five campaign parameters onto a URL you already have. Use it when an ad, an email, or a social post should show up as its own row later. It does not track the click. Tracking starts on the page the link opens, if that page runs analytics.

The page speed checker is one Lighthouse lab visit from Google. It is a useful first look at LCP, CLS, and the heaviest opportunities. It is not a record of your visitors. Real INP needs field data. When Google does not have that, the checker shows Total Blocking Time and says it is a lab proxy.
